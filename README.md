# DevOps & Platform Engineering Portfolio

End-to-end DevOps and Platform Engineering implementation covering
application development, Kubernetes, AWS, Helm, GitOps, CI/CD,
service mesh, security, and infrastructure automation.

## 📂 Repositories

### 1. Employee Application
Java/Spring Boot application used as the workload for the platform.

- Java / Spring Boot
- Docker
- REST API
- MySQL
- CI/CD

🔗 [Employee App](https://github.com/rahulkishorparida/employee-service)

### 2. Platform Infrastructure
Infrastructure and platform components required to run the application.

- AWS / EKS
- VPC
- Subnets & Availability Zones
- IAM
- Kubernetes platform components
- Infrastructure automation

🔗 [Platform Infrastructure](https://github.com/rahulkishorparida/platform-infra)

### 3. Employee Helm
Helm-based deployment configuration for the employee application.

- Helm
- Kubernetes Deployment
- Service
- ConfigMap / Secrets
- HPA
- Environment-specific values

🔗 [Employee Helm](https://github.com/rahulkishorparida/employee-service-gitops)

### 4. Kind / Kubernetes Platform
Local Kubernetes platform used to implement and demonstrate
cloud-native DevOps and security practices.

- Kind
- Istio Service Mesh
- Argo CD
- Argo Rollouts
- Canary Deployments
- Subset-based Traffic Routing
- Ingress Traffic Routing
- VirtualService & DestinationRule
- OPA Gatekeeper
- NetworkPolicy
- mTLS
- AuthorizationPolicy

🔗 [Kind Platform](https://github.com/rahulkishorparida/platform-gitops)
